# StarkIndustries — Mark3 Settings Web Interface

A local web UI for configuring all Mark3 settings in one place.

**Stack**: Node 20 + Express 5 (backend) · React 18 + Vite + Tailwind CSS (frontend) · TypeScript

**Managed files**: `.env`, `models.config.yaml`, `Agents.md`, `projects/*.yaml`, `.claude/settings.json`

## Quick Start
```bash
npm install
npm run dev   # http://localhost:3100
```
